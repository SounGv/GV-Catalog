# GV print agent

โปรแกรมเล็กๆ บนคอมที่ต่อเครื่องพิมพ์ ให้หน้า "พิมพ์สติกเกอร์บาร์โค้ด" และ "แปลง Packing List · ใบแปะลัง" ส่งขนาดใบตรงเข้าเครื่องพิมพ์ (ใบแปะลังพิมพ์หลายใบ / ใบแรกหลังฉีกกระดาษ ไม่เลื่อน) ไม่ต้องเลือกกระดาษใน Chrome หรือไดรเวอร์

- เปิดโปรแกรม: ดับเบิลคลิก `GV-Print.bat` ไม่ต้องติดตั้งอะไร (ใช้ PowerShell ของ Windows) หน้าต่างต้องเปิดค้างไว้ตอนพิมพ์
- เปิดครั้งแรกจะใส่ทางลัดไว้ใน `shell:startup` ให้เปิดเองทุกครั้งที่เปิดคอม (ลบทางลัดนั้นออกได้ถ้าไม่ต้องการ)
- รองรับตอนนี้: TSC TE210 (TSPL) เครื่องอื่น หรือถ้าไม่ได้เปิดโปรแกรม หน้าเว็บจะพิมพ์ผ่านหน้าต่างพิมพ์ของ Chrome เหมือนเดิม
- ทุกงานส่ง SIZE 100x150 / GAP 3 mm ไปด้วย และปรับเทียบเซนเซอร์ช่องว่าง (GAPDETECT) ตอนพิมพ์ครั้งแรกหลังเปิดโปรแกรม สติกเกอร์ว่างเลื่อนออกมา 2-3 ดวงในครั้งนั้น
- รับงานเฉพาะจากเครื่องนี้ (127.0.0.1) และจากหน้า localhost / gv-catalog*.vercel.app
- ถ้าพิมพ์ออกมาสีกลับ หรือกลับหัว: แก้ `$Invert` / `$Direction` ที่หัวไฟล์ `gv-print-agent.ps1`
- `gv-print-agent.mjs` + `start-agent.bat` คือรุ่น Node.js เดิม ทำงานเหมือนกัน (ใช้ได้ถ้าเครื่องมี Node.js)
