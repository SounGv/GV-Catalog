ติดตั้งโปรแกรมพิมพ์ (TSC TE210)

ให้หน้าพิมพ์สติกเกอร์ส่งขนาดสติกเกอร์ตรงเข้าเครื่องพิมพ์ ไม่เลื่อน ไม่ต้องเลือกกระดาษใน Chrome

กำลังตรวจโปรแกรมพิมพ์บนเครื่องนี้…

1. ติดตั้ง Node.js (ครั้งเดียว)

ดาวน์โหลดรุ่น LTS จาก nodejs.org แล้วติดตั้งตามขั้นตอนปกติ

2. ดาวน์โหลดโปรแกรมพิมพ์

ดาวน์โหลด gv-print-agent.zip

คลายซิปไว้ที่ไหนก็ได้บนคอมที่ต่อเครื่อง TSC TE210 (เช่น C:\gv-print-agent)

3. เปิดใช้งาน

  1. ดับเบิลคลิก start-agent.bat ต้องเปิดหน้าต่างดำค้างไว้ตอนพิมพ์
  2. กลับไปหน้าพิมพ์สติกเกอร์ / หน้า AIS เลือกเครื่องพิมพ์ TSC TE210 หน้าจะขึ้นว่า "โปรแกรมพิมพ์เปิดอยู่"
  3. พิมพ์ครั้งแรก เครื่องจะวัดช่องว่างสติกเกอร์โดยเลื่อนสติกเกอร์เปล่าออกมา 2–3 ดวง ซึ่งปกติ

ให้เปิดอัตโนมัติทุกครั้งที่เปิดเครื่อง: กด Win + R พิมพ์ shell:startup แล้วนำทางลัด (shortcut) ของ start-agent.bat ไปวาง

ถ้าสีกลับด้าน (ดำเป็นขาว)

เปิดหน้าต่าง Command Prompt แล้วรัน set GV_PRINT_INVERT=0 ก่อนเปิดโปรแกรม หรือแจ้งผู้ดูแลระบบ
