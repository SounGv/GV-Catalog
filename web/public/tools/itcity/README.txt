- ไม่บวกยอด PR, TRB และ PO ซ้ำกัน

SKU และบาร์โค้ด
- ไม่แสดงบรรทัด SKU ระบบ บนใบส่งของ แต่ยังคงข้อมูลไว้ในตารางตรวจและ Excel
- ใช้รุ่นจากชื่อสินค้าและ GTIN เทียบกับ SKU ระบบ รักษารุ่นย่อยและ BOX
- ใช้ GTIN ตัวแรกของระบบ ไม่ใช้ PART_NO ของลูกค้าเป็นบาร์โค้ด
- หากลูกค้าระบุหลายบาร์และมีบาร์ระบบอยู่ในรายการ จะแสดงว่าตรงกับหนึ่งในบาร์ลูกค้า
- รุ่นตรง แต่บาร์ต่าง จะแสดงคำเตือนพร้อมบาร์ระบบและบาร์ลูกค้า
- ก่อนเปลี่ยนบาร์จริงต้องยืนยันกับลูกค้า โปรแกรมไม่แก้ข้อมูลสินค้าอัตโนมัติ
- ไม่พบรุ่น พบหลายรุ่น บาร์กับรุ่นขัดแย้งกัน หรือข้อมูลไม่ครบ จะให้ตรวจสอบ
- ไม่พิมพ์สติกเกอร์บาร์โค้ดสินค้า โปรแกรมนี้ทำใบส่งของและสรุปออเดอร์

- ค้นหาและกรองสถานะใช้กับตาราง Matrix/ตรวจบาร์เท่านั้น ไม่ตัดสินค้าออกจากใบส่งของ
