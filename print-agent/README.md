# GV print agent

โปรแกรมเล็กๆ บนคอมที่ต่อเครื่องพิมพ์ ให้หน้า "พิมพ์สติกเกอร์บาร์โค้ด" ส่งขนาดสติกเกอร์ตรงเข้าเครื่องพิมพ์ ไม่ต้องเลือกกระดาษใน Chrome หรือไดรเวอร์

- เปิดโปรแกรม: ดับเบิลคลิก `start-agent.bat` (ต้องมี Node.js) หน้าต่างต้องเปิดค้างไว้ตอนพิมพ์
- เปิดอัตโนมัติตอนเปิดเครื่อง: ทำ shortcut ของ `start-agent.bat` ไปไว้ใน `shell:startup`
- รองรับตอนนี้: TSC TE210 (TSPL) เครื่องอื่น หรือถ้าไม่ได้เปิดโปรแกรม หน้าเว็บจะพิมพ์ผ่านหน้าต่างพิมพ์ของ Chrome เหมือนเดิม
- รับงานเฉพาะจากเครื่องนี้ (127.0.0.1) และจากหน้า localhost / gv-catalog*.vercel.app
- ถ้าสติกเกอร์ที่พิมพ์ออกมาสีกลับกัน (ดำเป็นขาว) ให้เปิดด้วย `set GV_PRINT_INVERT=0`
- โดเมนอื่นเพิ่มได้ด้วย `set GV_PRINT_ORIGINS=https://โดเมน`
